# 🍓 Pi CCTV

![Status](https://img.shields.io/badge/Status-In--Development-e91e63?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Rust-000000?style=for-the-badge&logo=rust&logoColor=white)

A high-performance, lightweight video surveillance system designed for **Raspberry Pi**. Built with a **Rust** backend for speed and safety, and a minimalist **Raspberry-themed** web interface.

---

## 📸 Hardware Setup

The system is optimized for low-power ARM devices like the Raspberry Pi 5 and Pi Zero 2W.



> **Current Hardware:** Raspberry Pi 5 / 8GB RAM / Camera Module V2

---

## ✨ Features

*   **Cyberpunk UI:** A sleek, raspberry-colored monitoring dashboard.
*   **Low Latency:** Real-time streaming powered by Rust.
*   **Multi-View Grid:** Adaptive layout for monitoring multiple units simultaneously.
*   **Minimalist Design:** Clean, readable, and focused on performance.

---

## 🛠 Tech Stack

*   **Backend:** Rust (Fast, safe, and efficient memory management).
*   **Frontend:** HTML5, CSS3 (Custom Cyberpunk theme), and JavaScript.
*   **Target:** Arch Linux ARM / Raspberry Pi OS.

---
